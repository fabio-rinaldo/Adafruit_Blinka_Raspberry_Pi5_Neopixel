# Changelog

All notable changes to this project will be documented in this file.

## Original source

This project is a fork of [Adafruit](https://www.adafruit.com/)'s [Neopixel](https://github.com/adafruit/Adafruit_Blinka_Raspberry_Pi5_Neopixel) library. 

It has been modified to allow full support of all 4 state machines available on the Raspberry Pi 5.

### Changed
